# 中文 Kompress：Markdown 子数据集教师标注 Prompt

## 1. 标注目标

教师模型的任务只有一个：

**从给定的中文 Markdown 自然语言片段中，抽取必须保留的原文片段，保持顺序，不得改写。**

这不是摘要，不是改写，不是润色，也不是重组。

## 2. 核心原则

必须同时满足：

1. 只能输出原文中已经出现过的字词或连续片段
2. 输出顺序必须与原文一致
3. 不允许增补原文没有的信息
4. 不允许同义改写
5. 不允许总结式重写

## 3. 应优先保留的内容

对于 Markdown 场景，优先保留：

- 标题或小标题
- 任务目标
- 背景前提
- 约束条件
- 验收标准
- 下一步 / TODO / 行动项
- 模型名、版本号、指标、数值
- 文件名、路径、命令名、接口名
- 关键结论

## 4. 可优先删除的内容

如果不影响理解，可删除：

- 寒暄语
- 重复表述
- 语气填充
- 与主任务无关的展开解释
- 低信息密度的连接句

## 5. 标准 Prompt

```text
你是一个“严格抽取式压缩标注器”。

任务：从下面这段中文 Markdown 文本中，只保留完成任务所必须的信息，输出压缩后的文本。

硬性要求：
1. 只能复制原文中已经出现过的字词或连续片段。
2. 不得改写，不得同义替换，不得总结重写。
3. 输出顺序必须与原文一致。
4. 优先保留：标题、任务目标、约束条件、验收标准、下一步、关键结论、模型名、版本号、数值、文件名、路径、命令名。
5. 删除低信息密度、重复、寒暄或不影响理解的内容。

只输出压缩后的文本，不要解释，不要加任何前缀。

原文：
{{text_original}}
```

## 6. 更强约束版 Prompt

如果发现教师模型仍在改写，可改用这一版：

```text
你现在做的不是摘要，而是“荧光笔抽取”。

请从原文中直接挑出必须保留的片段，像用荧光笔划重点一样输出。

要求：
- 只能从原文复制片段
- 不允许自己组织新句子
- 不允许替换词语
- 不允许改变顺序
- 如果某个标题、约束、数值、路径、模型名很重要，必须保留

只输出抽取后的结果。

原文：
{{text_original}}
```

## 7. 输出格式要求

第一版建议教师模型只输出纯文本：

- 不要 JSON
- 不要解释
- 不要“压缩结果：”
- 不要项目符号前缀，除非原文里本来就有

原因：

- 便于后续直接做字符级对齐
- 降低格式噪声

## 8. 正例特征

好的标注结果应满足：

- 一眼能看出是原文子序列
- 关键约束还在
- 指标和数值还在
- 结构线索没有完全丢
- 比原文明显更短

## 9. 反例特征

出现下面任一情况，应视为坏样本：

- 把“本周要完成”改写成“本周完成”
- 把“建议先跑 baseline 再扩实验”改写成“先做 baseline”
- 自己补出原文没有的总结句
- 删除了版本号、文件路径、关键数值
- 把标题层次完全丢掉，导致结构混乱

## 10. 人工抽检清单

每批至少抽检以下问题：

1. 输出是不是原文子序列
2. 有没有改写痕迹
3. 有没有漏掉限制条件
4. 有没有漏掉数值、模型名、路径
5. Markdown 结构线索是否保住了一部分

## 11. 首轮建议

首轮先不要追求特别激进的压缩率。  
优先目标应是：

**宁可稍微保守，也不要误删关键约束。**

等第一版质量稳定后，再去压得更狠。
