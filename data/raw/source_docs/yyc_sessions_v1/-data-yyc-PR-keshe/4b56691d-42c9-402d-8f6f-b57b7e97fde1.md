## 5. 几个重要建议

- **千万不要**直接 push 到 `main`，永远走分支 + PR
- **千万不要** `git push --force` 到共享分支（会覆盖别人工作）
- 提交前看一眼 `git status`，避免把 `.env`、模型权重、数据集等大文件/敏感文件提交进去
- 建议在仓库根目录建一个 `.gitignore` 把 `__pycache__/`、`*.ckpt`、`*.bin`、`data/`、`output/` 等排除
- 微调项目常涉及大模型文件，超过 100MB 的文件 GitHub 会拒收，需要 Git LFS 或放外部存储
