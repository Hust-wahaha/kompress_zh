发现两个需要先决策的点，不建议直接 `uv sync` 跑下去：

**1. 本机 NVIDIA driver 与 pyproject 锁的 torch 不匹配**
- 本机：`CUDA Driver 12.4`
- `pyproject.toml` 锁的是 `torch==2.11.0+cu130`（CUDA 13.0 toolkit 编译的 wheel）
- driver 只能兼容**等于或更低**版本的 CUDA toolkit，cu130 wheel 在 12.4 driver 上通常运行时会报 `CUDA driver version is insufficient`。而且 `+cu130` wheel 不在默认 PyPI 上，pyproject 里也没看到 `[tool.uv.sources]` 或额外 index 配置，`uv sync` 这一步多半就拉不到。

**2. Python 版本**
- 本机默认是 `miniconda Python 3.13.12`，项目要 `>=3.12` 且 AutoDL 实测 `3.12.3`。uv 会自动下一个 3.12 装到 `.venv`，无需依赖 conda，这部分不用你操心。
