## 1. 当前总体结论

在 `996` 主体阶段，当前数据集已经基本达到“`1k` 级高标准工作集”的目标；而在 `targeted400` 补洞并完成 merge 后，当前已形成第一版可直接用于训练的 `1k+` 标准集。

理由不是单纯因为数量接近 `1000`，而是因为：

- 生产链路已经连续跑通两轮 `500`
- `P2-only` 主路径已经稳定
- 人工轻审链路已经验证可用
- 数据风格、来源和任务形态已经不再只靠单一小池支撑

因此，当时更合理的主任务不是继续盲目扩大批次，而是：

- 先把这批 `996` 条当作当前标准集候选
- 做结构复盘与少量定向补洞
- 再定最终 `1k+` 标准集版本

## 3. 当前标准集的优点

### 3.1 主生产链路已稳定

已经验证：

- 大池扩源
- `500` 候选抽样
- teacher 全标
- review queue
- `P2-only` 审核
- 正式 merge

这说明标准集不再是“手工攒出来的一批样本”，而是来自稳定生产线。

### 3.2 风格已经较统一

- `teacher_prompt_version` 基本统一为 `balanced_v1`
- `style_tag` 全部为 `lite_wenyan_structured`

这对后续训练是好事，因为：

- 风格噪声低
- 模型更容易稳定学到目标表达

### 3.3 锚点样本已经有训练价值

当前 `contains_anchor=true` 样本占绝大多数，说明：

- 这不是普通摘要集
- 更接近我们目标里的“agent/plain-text compression”场景

## 4. 当前明显偏斜

### 4.1 长文本仍偏少

虽然已经有 `79` 条 long，但如果目标是部署可用：

- `700+` 仍不算多
- `1000+` 基本不够

这会导致：

- 模型在长文本上的稳定性判断仍偏弱

### 4.2 session / sync / decision 类语料偏少

当前标准集仍更偏“文档说明压缩”。

相对不足的是：

- session 对话上下文
- 执行日志式自然语言说明
- sync / 决策 / 下一步推进文本

这些内容恰好是实际 agent 使用中很重要的一类。

### 4.3 部分来源仍偏重

当前大来源仍偏集中在：

- `system_integration`
- `homecareclaw`

这不是灾难性问题，但会让标准集在语气、任务密度、结构习惯上带明显来源印记。

## 5. 当前建议

### 5.1 当时为何不建议立刻再开完整第三组 `500`

原因：

- 当前已到 `996`
- 标准集目标已基本达成
- 此时继续大批扩量，收益会低于定向补洞

### 5.2 当时建议的“小规模定向补洞”已完成

目标不是再扩很多，而是把标准集收得更稳；该动作现已完成。

- 实际执行为一轮 `targeted400`
- teacher 全标 `400` 条后，`P2-only keep pool = 238`
- final audit sample `23` 条全通过
- 最终将当前主数据集由 `996` 推进到 `1234`

结论：

- 原先关于长文本、session / sync / next-step / delivery / risk 风格文本不足的判断是对的
- 定向补洞策略有效，且实际产出强于保守预估
- 当前不必再为“刚过 1000”而补一轮小批，主线应先转入训练

### 5.3 当前标准集口径

原先建议下一版正式标准集目标设为：

- `1030 ~ 1080`

而不是卡死在整数 `1000`。当前实际结果为：

- `v6 standard-set = 1234`

这高于当时的保守目标，但并不意味着方向跑偏。原因是：

- 本轮定向批次质量较稳，`P2` 转化率可接受
- 新增样本更偏长文本、强锚点与部署风格文本
- 当前更需要的是尽快用这版标准集启动正式训练，验证模型是否真正学到目标能力

因为真正重要的是：

- 结构更均衡
- 长文本更稳
- agent 现场语境更充分

## 6. 下一步最推荐动作

当前最推荐的顺序：

1. 将 `1234` 条 `v6 standard-set` 视为当前正式训练主集
2. 基于该版本启动正式训练与评测
3. 训练后再看长文本、强锚点与 session 风格 case 的真实泛化表现
4. 若仍需扩源，将新批次作为并行副线推进，而不是阻塞当前主线

一句话结论：

当前 `1234` 条 `v6 standard-set` 已经构成第一版可直接用于正式训练的高标准中文压缩工作集。`996` 主体阶段的结构判断是有效的，`targeted400` 的定向补洞策略也已经被实践验证；下一步不应继续为扩量而扩量，而应先用这版主集把训练与评测做扎实。
