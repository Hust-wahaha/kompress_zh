# Windows 本地开发依赖清单

# 适用范围（实测 RTX 4060 Laptop 8GB）：
#   - 数据生成 / 校验 / 文档维护
#   - LoRA 微调（max_length=1536 项目默认）
#   - 评测（scripts/eval.py）
#
# 重要说明：
#   - torch 必须 >= 2.6，不要用 conda pytorch 频道（上限 2.5.1，无 FSDPModule，ms-swift 4.x 无法导入）
#   - ms-swift 4.x 依赖 FSDPModule（torch.distributed.fsdp），该类在 torch 2.6+ 才有
#   - 不要用 Anaconda base Python 做 venv base，会触发 torch c10.dll 初始化失败
#   - Windows 训练时须加 --dataloader-num-workers 0（multiprocessing spawn 限制，train_lora.py 已设为默认）
#
# ★ 推荐方式：uv 虚拟环境（.venv，已实测，Python 3.12 + torch 2.8.0+cu126）：
#   uv python install 3.12
#   uv venv --python 3.12 .venv
#   # torch 从 cu126 wheel 安装（2.8.0+cu126 已含 FSDPModule）
#   uv pip install --python .venv\Scripts\python.exe torch==2.8.0+cu126 torchvision==0.22.4+cu126 \
#       --extra-index-url https://download.pytorch.org/whl/cu126
#   uv pip install --python .venv\Scripts\python.exe --index-strategy unsafe-best-match \
#       -r requirements_windows.txt
#
# 备用：pip + cu126 索引（需 Python 3.12）：
#   pip install torch==2.8.0+cu126 torchvision==0.22.4+cu126 \
#       --extra-index-url https://download.pytorch.org/whl/cu126
#   pip install -r requirements_windows.txt
